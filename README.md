# دفتر — منصة المحاسبة الذكية

واجهة أولية عالية الجودة لمنصة محاسبة عربية تعمل باتجاه RTL، مبنية باستخدام React وTypeScript وVite.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يعرضه Vite في المتصفح.

## ما تم تضمينه

- لوحة تحكم مالية متجاوبة بالكامل باللغة العربية.
- مؤشرات الرصيد والدخل والمصروفات وصافي الربح.
- رسم تفاعلي للتدفق النقدي باستخدام Recharts.
- رؤى ذكية قابلة للتطوير لإضافة نموذج الذكاء الاصطناعي لاحقاً.
- جدول الفواتير مع حالات الدفع.
- قائمة جانبية، مساحة عمل، إشعارات، وتصميم مناسب للجوال.

## خارطة الطريق التقنية

1. إضافة مصادقة المستخدم وقاعدة بيانات PostgreSQL.
2. بناء API للمعاملات والفواتير والعملاء باستخدام Node.js أو Supabase.
3. ربط خدمة OCR لاستخراج بيانات الفواتير تلقائياً.
4. إضافة طبقة تحليل مالي آمنة تعتمد على نموذج ذكاء اصطناعي مع إخفاء البيانات الحساسة.
5. إضافة صلاحيات الفريق، الضرائب، التصدير PDF/Excel، وسجل التدقيق.
